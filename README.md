# 🚀 Afandi Online Fix Launcher



**Afandi Online Fix Launcher** is a professional automation tool designed to streamline the installation of Steam Online Fixes. It eliminates the manual struggle of locating directories by using a smart scanning algorithm to place emulator files exactly where they belong.

---

##  Key Features

* ** Deep Search Algorithm:** Automatically scans all subdirectories to find `steam_api.dll` or `steam_api64.dll`, regardless of how deep they are hidden (ideal for Unreal Engine & Unity games).
* **🎯 Smart Dual-Placement:** * Injects the **Proxy DLL** (`version.dll`) and configuration files directly next to the game's main `.exe`.
    * Replaces the **Steam API** in its specific internal folder.
 context menus for seamless path and AppID entry.
* **🎮 Gaming UI:** A modern, dark-themed interface built with `CustomTkinter`.
* **⚙️ Auto-Configurator:** Generates the `afandi.ini` file and creates the `plugins` directory automatically based on user input.

---
How to Use
​Launch the application.
​Browse or Paste the path to your Main Game Folder.
​Enter the Original AppID (e.g., ...).
​Toggle Options: Choose whether to enable the Steam Overlay.
​Install: Click INSTALL FIX. The launcher will scan, download, and configure everything.
​Play: Ensure Steam is running, then launch your game and enjoy the online experience!
​📂 Repository Structure
​/x32: Contains 32-bit fix binaries.
​/x64: Contains 64-bit fix binaries.
​launcher.py: The main GUI application source code.
